      'Actions', useActionState and 'useFormStatus' hooks.
      These simplily form submition, loading states and error handling.

    React 18 forms:
                      form handling involves using 'usestate()' to track input values.
                       writing 'onchange' handles for eachfield handling submissiton via handleSubmit()
                       funtion.
     React 19 form enhancements:
            React 19 introduces Actions, which are aynchornous functions designed to simplify form logic.

            Handle form submistion declaratively, track pending states with 'useFormStatus,
             manage form state within 'useActionState()'

      Actions are aynchornous functions that form logic we pass them directly to the forms action attribute.

      key feturesin react 19 forms:
         - Actions -> Thes are aynchornous functions that handle form submissiton. 
           Instead of manually managing state state and side effects, we defined an action function and pass to the form.

         - 'useActionState'  -> it is new hooks been introduce in react 19. this hook tracks the state of an action
            (e.g. loading, succes, error). it replaces manual 'useState' and 'useEffect' logicc form submition.
             'useActionState()'
              - it takes two parameter.
               1.  form submit handler function to handle logic after user click on button.
               2. object to specify the intial stae of form.

          - 'useformStatus' -> 'its a new hooks has been introduced from react 19, this hook
             provides realtime staus of the fom(e.g pending,submitted). It is useful for disableing buttons or showing
             spinners during submissiton.

React Routing 
react-router-dom(V7) is the standard library for implementing dynamic, client-side routing in React web applications

 Routing enables us to create Single-Page Applications (SPAs) where navigation occurs without a full page reload. 

Core components and hooks been supported in react-router-dom lib :

<BrowserRouter>	Wraps the entire application to enable routing functionality using the browser's History API.

<Routes>	A container component that looks through its children <Route>s and renders the first one that matches the current URL.

<Route>	Defines a mapping between a specific URL path and the element (component) that should be rendered when that path is matched.

    <Route path="/" element={<Home />} />


<Link>	Used for navigation between different routes. It's a replacement for the HTML <a> tag that prevents full page reloads.

useNavigate()	A hook used for programmatic navigation, such as redirecting a user after a form submission or login.

useParams()	A hook that allows access to dynamic segments of the URL (e.g., :id in /user/:id).

<Outlet>	Used in parent routes to specify where the child routes should be rendered, enabling nested layouts.

Modern Features (v6.4 & v7)
Recent versions introduced "Data APIs" that allow you to manage data fetching and mutations directly within your route definitions: 
Loaders: Functions that fetch data before a route renders.
Actions: Functions used for handling data mutations (e.g., POST requests from <Form>).
RouterProvider: The recommended way to initialize a router when using these advanced data features.

Higher order components: 
In React, a Higher-Order Component (HOC) is an advanced pattern used for reusing component logic. It is not a part of the React API, per se, but rather a pattern that emerges from React's compositional nature.

At its core, an HOC is a function that takes a component and returns a new component. HOC is not actually a component instead it is function. 

The Basic Concept
Think of an HOC as a "wrapper" that injects extra functionality, data, or styling into an existing component without modifying the original component's code.

How it Works
The syntax usually looks like this:

JavaScript
const EnhancedComponent = higherOrderComponent(WrappedComponent);

Key Characteristics:
Pure Functions: An HOC should be a pure function with no side effects. It shouldn't modify the input component;
 it should use composition.

Logic Reuse: Great for handling repetitive tasks like fetching data, checking authentication, 
or logging analytics.

-----------
React Fiber: 
React Fiber is the reimplementation of React’s core reconciliation algorithm introduced in React 16, 
designed to make rendering smoother, more flexible, and capable of handling complex UI updates like 
animations and gestures. Its key innovation is incremental rendering, which allows React to break work 
into chunks and prioritize updates for better responsiveness.

- Definition: React Fiber is the new reconciliation engine in React, replacing the older stack-based algorithm.
- Introduced: In 2017 with React 16.
- Purpose: To improve responsiveness and enable advanced features like concurrency, prioritization, 
and interruption of rendering tasks

Core Features
- Incremental Rendering: Breaks rendering work into units and spreads them across frames, keeping the UI responsive.
- Prioritization: Assigns priority to updates (e.g., user input > background data fetching).
- Interruptible Work: Rendering can be paused, aborted, or reused when new updates arrive.
