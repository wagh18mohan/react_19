Parentheses: None here, so move to the next rule.

Exponents: Not applicable.

Multiplication, Division, Modulus (from left to right):

Calculate 20 * 5: 20 * 5 = 100 Now the expression becomes: 10 - 100 + 100 % 30

Calculate 100 % 30 (remainder of 100 divided by 30): 100 % 30 = 10 Now the expression becomes: 10 - 100 + 10

Addition and Subtraction (from left to right):

First, 10 - 100: 10 - 100 = -90

Then, -90 + 10: -90 + 10 = -80

Final Result = -80

In JavaScript, there are several types of errors that can occur during code execution.
 Here are the main types:

1. Syntax Errors – Also known as parsing errors, these occur when the JavaScript
 code is written incorrectly, preventing proper execution.
  Example: console.log("Hello) (missing closing quotation mark).

2. Reference Errors – Happen when a variable is used before it is defined,
 or if there is a misspelled variable name. Example: console.log(myVar); 
 when myVar has not been declared.

3. Type Errors – Occur when an operation is performed on a data type that is not 
compatible. Example: Trying to call a method on undefined: null.toUpperCase();.

4. Range Errors – Arise when a value is set beyond its allowed range,
 like setting an invalid array length. Example: let arr = [];
  arr.length = -5; (array length cannot be negative).

5. Eval Errors (Rare) – Related to the incorrect use of the eval() function, 
though modern JavaScript discourages its use for security and performance reasons.

6. URI Errors – Occur when global URI-handling functions (decodeURI(), encodeURI())
 are used incorrectly. Example: decodeURIComponent('%') (an incomplete encoded URI).
